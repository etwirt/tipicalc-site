Release notes

v1.9.0 — 2026-08-23

  • Single-argument functions can now be written without parentheses (e.g., sin x, sin x * cos x, sqrt 9); such a call binds to the next factor only — tighter than *, /, looser than ^

v1.8.0 — 2026-08-22

  • Time arithmetic: added support for time literals (e.g., 1d, 3h, 7m)
  • Time arithmetic: support spaces in time format (e.g., 10 42 instead of 10:42)

v1.7.2 — 2026-03-15

  • Visual improvements

v1.7.1 — 2026-03-15

  • Added Settings page (Themes: Light/Dark/Auto, Font size, Window size)
  • Moved "Clear history" button to the menu
  • Added confirmation for clearing history

v1.6.0 — 2025-12-26

  • Added ability to delete individual items from history

v1.5.0 — 2025-12-25

  • UI improvements and fixes (show the current version, Web Store link, Release notes link)

v1.4.0 — 2025-11-26

  • An ability to open the extension in a new window was added

v1.3.0 — 2025-11-20

  • Time arithmetic mode was added

v1.2.0 — 2025-11-01

  • Persisted the last typed expression between popup sessions

v1.1.1 — 2025-10-28

  • Adjusted internal logging so invalid expressions don’t count as errors

v1.1.0 — 2025-10-27

  • Fixed precedence of exponent (^) and unary minus
  • Corrected calculations with @ when its value is positive
  • New functions: gcd, lcm, avg, is_prime
  • Extended: random
  • Operator additions: synonym : for division, support for unary plus
  • Improved history selection when it’s full

v1.0.0 — 2025-09-28

  • Initial release
