Examples

  • sqrt(9) → 3
  • root(3, 8) → 2
  • ln(e) → 1
  • lg(1000) → 3
  • log(8, 2) → 3
  • sin(pi/2) → 1
  • 7 // 3 → 2
  • frac(3.14) → 0.14
  • @ * 2 — previous result * 2

Time arithmetic mode

  • time 10:50+18 → 11:08
  • t -1:00 + 0:30 → -0:30
  • !t 2:00 - 0:30 → 1:30
  • time 18 + 1:00 → 1:18
  • time :30 + 0:45 → 1:15
  • t -:05 + 1:00 → 0:55
  • Invalid: time 10:5 — minutes must be two digits
